# OMT — OOOOOAO's Eve Map Tool

A fork of [Slazanger/SMT](https://github.com/Slazanger/SMT), the EVE Online map tool.
The tool itself is Slazanger's work; this repository just carries changes on top of it.

Installers are published under [Releases](https://github.com/OOOOOAO/SMT/releases).
They are built by the `Package installer` workflow, which runs when a `v*` tag is
pushed — the tag name has to match `SMT_VERSION` in `EVEData/EveAppConfig.cs`, because
the in-app update check compares the two literally.
